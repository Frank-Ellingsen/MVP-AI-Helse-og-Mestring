# Kristiansand Kommune — Control Office Hub & Visual Sandbox

Dette repositoryet inneholder **Control Office Hub** for Helse og Mestring i Kristiansand kommune.

## Innhold
- **FT Visual Vocabulary Sandbox (36 Suite)**: Visualiseringer basert på Edward Tufte Data-Ink Ratio og FT-kategorier.
- **Multi-Agent System & Looped AI Engineering**: Bounded loops, selvkorrigerende SQL og Human-in-the-Loop.
- **Power BI DAX Suite**: Klare DAX-formler for EOY-prognoser og CPI.

## Hurtigstart
```bash
docker compose up --build
```
