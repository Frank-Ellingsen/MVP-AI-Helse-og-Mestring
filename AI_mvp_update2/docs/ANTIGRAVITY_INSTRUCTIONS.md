# Antigravity AI Agent — Utviklingsinstruks

## Oppgave
Videreutvikle `MVP-AI-Helse-og-Mestring` ved å integrere LangGraph subgraphs og utvide FT Visual Sandbox med nye Plotly/Altair-komponenter og DAX-mål for Power BI.

## Kilder
- `app/visual_sandbox.py`: Inneholder 36 Visuals Suite og DAX.
- `app/agent.py`: Inneholder Multi-Agent Supervisor.
- `app/schemas.py`: Pydantic v2 datakontrakter.
